# Christmas Cookie To-Do List

A simple Christmas-themed to-do list web app with a cozy twist. You can manage tasks and create fun cookie-style sticky notes for quick reminders — all in a festive, visual layout.

Everything saves directly in your browser, so your tasks and notes are still there when you come back.

---

## Features

- Add, complete, and delete tasks
- Create cookie-style sticky notes for reminders
- Saves automatically in the browser (localStorage)
- Festive UI with a custom background and holiday styling
- Mobile-friendly responsive layout
- Lightweight — built with pure HTML, CSS, and JavaScript (no frameworks)

## How to Use

1. Clone or download this repository  
2. Make sure these files are in the same folder:
   - `index.html`
   - `background.jpg`
   - `cookie.png`
   - `demo.mp4` (not required)
3. Open `index.html` in your browser  
4. Start adding tasks and cookie notes

---

## Tech Stack

- HTML5  
- CSS3  
- Vanilla JavaScript  
- LocalStorage API

## Notes

- Data is stored locally in your browser only  
- No backend or database required  
- Works offline once loaded
- Best experience on Firefox (mobile and desktop). Other browsers may render spacing and layout slightly differently due to CSS handling differences.
